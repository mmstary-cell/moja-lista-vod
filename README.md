# Netflix PL – moja lista

Prywatna aplikacja (PWA) na telefon: katalog Netflix Polska z ocenami Filmweb i IMDb,
filtry (film/serial, gatunek, ocena), oznaczanie obejrzanych, ciemny motyw i duże litery.

* Aplikacja: folder `docs/` (publikowana przez GitHub Pages)
* Aktualizacja danych: `scripts/update.py`, uruchamiana przez `.github/workflows/update.yml`
  codziennie oraz na żądanie (przycisk ⟳ w aplikacji)

Źródła danych: TMDB (dostępność: JustWatch), IMDb Non-Commercial Datasets, nieoficjalne API Filmweb.
This product uses the TMDB API but is not endorsed or certified by TMDB.

Instrukcja instalacji: plik `SETUP_GUIDE.html`.
